# 03 接口契约

## 1. 数学服务（services/math-service）

启动：`python -m mathsvc.server`。环境变量：`MATH_SERVICE_KEY`（≥32 字节，与平台 FLOW_MATH_SERVICE_KEY 相同）、`MATH_DATA_DIR`、`MATH_LISTEN`。

### REST（平台内部适配）
每个请求带 `X-Math-Context: base64url(JSON{tenant_id, actor, purpose, exp})` 与
`X-Math-Signature: hex(HMAC-SHA256(key, ctx_b64 \n METHOD \n PATH \n sha256hex(body)))`。上下文过期或有效期过长时拒绝（POLICY_REVOKED）。tenant 只取自签名上下文，请求体中的 tenant 不被信任。

| 方法与路径 | 说明 |
| --- | --- |
| GET /healthz | 无鉴权；版本与目录版本 |
| GET /v1/catalog | 题族目录与限制 |
| POST /v1/jobs | `{kind: analyze或lesson_build, idempotency_key, problem, problem_hash, …}`；新建返回 202，同键同输入返回 200 原作业，同键不同输入返回冲突 |
| GET /v1/jobs/{mj_…} | 作业视图（schema `edu.math.job/1`） |
| POST /v1/jobs/{id}/cancel | 协作式取消（阶段之间生效） |
| POST /v1/reconcile | `{kind, idempotency_key}` → `{found, job}`；只查询，从不执行 |
| POST /v1/grade | `{expected:{exact, plain}, response, approx:{allowed, rel_tol}, unit_policy}` → `{result, reason, grader}`。同步，在与作业阶段相同的隔离子进程中运行（空环境、资源上限、10 秒超时）。result 取值 correct、correct_approx、incorrect、needs_exact、needs_teacher、invalid。返回值从不包含期望答案。学生文本只经白名单解析，不 eval。区间只接受 `[a, b]`；文字、步骤与证明一律 needs_teacher |
| POST /v1/normalize | DEV-031 文字题目识别。`{text}`（≤600 字）→ `{state: needs_confirmation, family_id, structured, summary{object, conditions, target, unit, method, method_stated}, problem_text}`。在与作业阶段相同的隔离子进程中运行（2 秒 CPU 预算）。只按题族固定整句表述识别，不按相似度；数字经题族准入检查，不 eval。拒绝时返回错误码与 details.reason（固定中文原因） |
| GET /v1/artifacts/{ma_…} | 产物正文；头部 X-Artifact-Sha256、Audience、Kind |

### MCP（Streamable HTTP，POST /mcp）
Bearer 令牌由平台签发（edumath.MCPToken，带租户与过期时间）。工具：math_analyze_start、math_lesson_build_start、math_media_render_start（未配置供应商时返回 PROVIDER_UNAVAILABLE）、math_job_get、math_job_cancel、math_call_reconcile、math_artifact_get（HTML 与媒体不进入模型上下文，只给元数据）。幂等键可放在参数或 `_meta.idempotency_key`。已用 Go MCP SDK v1.6.1 客户端验证（TestMCPProtocolWithGoSDK）。

### Agent 侧数学工具（W10，FR-P01、FR-P03、FR-P04）
主 Agent 通过两条受控路径使用数学能力，都不放宽全局出站策略：

1. **平台适配工具（启动与等待）**：`mcp_platform_math_analyze_start{problem_revision_id}`、`mcp_platform_math_lesson_build_start{solution_revision_id}`、`mcp_platform_math_job_wait{job_id, max_wait_seconds 1 至 20，默认 10}`、`mcp_platform_math_job_cancel{job_id}`。实现为 edumath.AgentTools，经平台作业执行，因此预算预留、价格版本、阶段唯一结算全部由 Go 账本负责（约束 6、FR-B01）。只在安装了 education-math 行业包的工作区出现（FR-P03），每次调用重新解析教师身份（撤销立即生效，恢复时同样复核，AC-36）。幂等键为 Agent 工具调用（`agent:tool:<会话>:<调用>`），重放返回原作业。等待工具分段等待，未完成时返回 `resume`（再次调用 math_job_wait 的参数），等待不会重启或重复收费（AC-38）。返回值只含标识、状态、数学状态、证据层级与下一步，不含课件 HTML、媒体或学生材料（FR-P07）；审核、发布、布置不在工具中，只能在应用中由有权用户执行（FR-P01）。参数按精确 Schema 校验，目录外工具名一律未知。
2. **精确内网 MCP 目标（只读查询）**：部署变量 `FLOW_MCP_INTERNAL_TARGETS` 为 JSON 数组 `[{endpoint, tools[], credentialRef}]`。只有端点字符串完全一致的连接才可使用 http 或内网地址；拨号固定到该 host:port，拒绝重定向，链路本地与元数据地址（169.254.0.0/16、metadata 主机名）在配置时与连接时都拒绝；只能批准列表中的工具，列表缩小后未重新批准也立即生效（不再提供、不再执行）；从配置中删除目标后连接不可达。`credentialRef: "mint:edumath"` 由平台为连接所属租户签发 5 分钟有效的数学服务令牌（edumath.MCPToken），平台密钥不出后端，也不会发往非内网目标。建议只列 `math_job_get`、`math_artifact_get`；启动类工具保留在平台适配路径上，否则会绕过 Go 账本（待确认问题 14）。

示例：`FLOW_MCP_INTERNAL_TARGETS='[{"endpoint":"http://math-service:8090/mcp","tools":["math_job_get","math_artifact_get"],"credentialRef":"mint:edumath"}]'`

### 作业视图
`{schema_version, job_id, kind, status, stage, progress, seq, result_refs[{artifact_id, kind, audience, sha256, media_type}], usage[{stage, unit: compute_ms, quantity}], warnings, error{code, message, retryable, next_action}}`

状态：queued、running、needs_confirmation、succeeded、failed、cancelled、reconciliation_required（平台侧）。阶段：validate_input、solve、verify、compose_lesson、project_student、render_preview、check_render（DEV-082，讲解与编辑作业的末阶段，产物 render_check 仅教师可见）。

产物：solution 与 validation_report（teacher）、lesson（teacher）、lesson_student（student）、preview_html（teacher）、preview_html_student（student）。

### 回执严格校验（W13，DEV-053）
平台适配器对作业回执失败关闭，不截断、不猜测：
- 大小：作业回执与对账回执上限 1 MiB，产物上限 16 MiB；超限整体拒绝，不截取后解析。
- 解码：只接受一个 JSON 值，未知字段与尾随数据都拒绝；服务附加字段 request_id、trace_id、usage_state、catalog_version 已列入契约。
- 字段：job_id 必须是 mj_ 加 32 位十六进制；kind 已知；input_hash 为 sha256 加 64 位十六进制；seq 至少为 1；progress 在 0 到 1 之间；阶段列表必须与该 kind 的流水线逐项同名同序，阶段状态取 pending、running、succeeded、failed、skipped、cancelled；succeeded 作业的阶段必须全部完成；failed 作业必须带 error；用量只能指向已完成或失败的阶段，每阶段至多一条。
- 产物引用：artifact_id 为 ma_ 加 32 位十六进制且不重复，kind 非空，audience 为 teacher 或 student，size 在 1 字节到 16 MiB 之间，media_type 取白名单 application/json、text/html; charset=utf-8、image/svg+xml、image/png、audio/mpeg、video/mp4、text/vtt; charset=utf-8（兼容非文本资源）。
- 产物下载：正文 sha256、X-Artifact-Sha256、长度、Content-Type、X-Artifact-Kind、X-Artifact-Audience 必须与登记一致。
- 处理：运行中收到无效回执时不应用，保留上次有效状态，作业 error 记为 RECEIPT_INVALID，下一次有效回执覆盖该记录。服务报告成功但产物校验失败（截断、篡改、类型不符）或产物内容缺少必需字段时，作业转为 failed，error 为 RECEIPT_INVALID，不生成任何修订；已运行阶段按实际计算各结算一次；编辑头释放。提交回执无效时按未知结果处理，按原键对账，不盲目重发。

### 部分产物（W13，DEV-054）
`GET /api/edu/jobs/:id`（仅教职人员）返回 `artifacts[{id, kind, audience, mediaType, sha256, size, partial}]`，只有元数据，没有内容和链接。作业未成功时 partial 为 true：这些产物留作审计，不会物化为解答、课件或变式修订。

## 2. 平台 API（/api/edu，edumath.API）

教师、审核员、机构管理员：请求带 X-Workspace-Id（空值表示个人工作区）且需有对应教育角色。机构管理员（非任课）读取个体学生记录（班级名单与名单条目，以及经 staffAssignment 的作业下作答、求助、批改、图形与变式接口）时须带 X-Edu-Access-Purpose（百分号编码的业务目的，解码后 4 至 200 字，不含尖括号与换行），否则 403 ACCESS_PURPOSE_REQUIRED（next_action state_access_purpose）；每次成功访问写审计 org.individual_access（详情为方法、路由与目的）。任课教师不受影响。学生：请求带 X-Edu-Tenant 且有 student 绑定。

## 3. 结算契约
- 根预留键 `edu:job:<job_id>`；阶段子预留 `edu:stage:<job_id>:<stage>`；每阶段唯一 EduStageRun。
- 用量类型 `math_compute_ms`，数量为阶段计算毫秒；RecordUsage 只记录，不重复扣费。
- 价格冻结（DEV-061）：作业受理时把当时的价格簿整份写入 edu_math_jobs.price_book，之后每个阶段都按这份价格计价，用量行的 price_version 与单价也取自这份价格簿；价格簿中途变更不影响已受理作业。v75 之前创建的作业没有冻结价格簿，按现行价格簿结算（07）。
- 阶段计费口径：状态为成功或失败的阶段按实际计算毫秒计费（失败阶段的计算已实际发生）；未开始、运行中被取消的阶段不计费。单阶段费用以根预留剩余额度为上限，超出部分不收。
- 终态（DEV-062）：settlement 取值 open、settled、released。有已计费阶段的终态作业为 settled（子预留已消费，余额退回）；没有任何已计费阶段的终态作业为 released（排队即取消、首阶段前失败，整笔预留释放）。reconciliation_required 期间 settlement 保持 open 且预留保持，直到对账。
- 取消（AC-41）：排队中取消不进入任何阶段，整笔释放；运行中取消只结算已完成阶段；结果未知期间取消先记录 cancel_requested，对账证明服务端未受理时直接置为 cancelled 并释放，绝不再次提交；对账发现已受理时补发一次取消。
- 账本对账与审计导出（DEV-063）：只有租户所有者、管理员或教育 org_admin 可用，教师与学生 403。`GET /api/edu/ledger/report?from&to&format=json|csv`（RFC3339，默认最近 31 天，最长 366 天）逐作业列出作业、根预留、阶段子预留、阶段记录与用量行的金额与状态，CSV 为 private、no-store 附件，每次导出写审计；`POST /api/edu/ledger/reconcile` 运行对账并把发现写入 edu_ledger_anomalies（同一作业同一类别只有一条）；`GET /api/edu/ledger/anomalies?status=`；`POST /api/edu/ledger/anomalies/:id {status: open|investigating|resolved, owner, note}`，调查中必须有负责人，解决必须有说明，已解决但再次对账仍存在的发现自动重开。发现类别：stage_unbilled、stage_child_mismatch、duplicate_stage_charge、usage_mismatch（条数、金额或价格版本不一致）、root_mismatch、settlement_stuck、over_budget、unknown_outcome_stale（结果未知超过 1 小时）、hold_after_close。
- 定时对账：worker 按 EDU_LEDGER_RECONCILE_EVERY（默认 24 小时，最短 5 分钟，off 关闭）对最近 35 天有数学作业的每个租户在其租户事务内运行同一对账，发现以 system:ledger 记录并审计 ledger.reconcile.scheduled；已存在的未解决发现只刷新，不重复。
- 机构预算与公平限流（DEV-064）：`GET /api/edu/budget`（本工作区教职）返回限额、周期（按 EDU_BUDGET_TZ，默认 Asia/Shanghai 自然月）、机构与本人本期已承诺金额、运行中作业数与本期提醒（非管理员只看到机构级与本人提醒）。`PUT /api/edu/budget`（租户所有者、管理员或 org_admin）`{monthlyMicro, teacherMonthlyMicro, maxActiveJobs, maxActivePerTeacher, maxRenderJobs, alertPercent, reason}`，0 表示不限，负数 400，写审计。已承诺金额等于本期已结算阶段费用加未关闭预留的整笔持有（结果未知也计入）。新作业受理前依次检查：机构与教师运行中上限、课件渲染（lesson_build、lesson_edit）并发上限，超出返回 429 RATE_LIMITED；机构与教师月预算，超出返回 402 BUDGET_EXCEEDED。被拒绝时不预留、不派发；同键幂等重放不受限；已有作业、课件与产物的读取从不受预算影响。达到 alertPercent（默认 80）记 warn，被预算拒绝记 exhausted，每周期、范围、级别各一次。Postgres 上按租户串行化受理检查，并发提交不会越过上限。
- 交付成本核算（DEV-065）：只有租户所有者、管理员或 org_admin。`GET /api/edu/cost-report?period=YYYY-MM`（按 EDU_BUDGET_TZ 自然月，作业按创建时间归期）返回分项 lines（component、source、metered、costMicro、quantity、unit）：compute_succeeded、render（render_preview 阶段）、failed_and_cancelled、open_holds（仅数量，不计成本）、storage（产物字节，无单价）、tts 与 egress（未接入，metered=false）、human_support；以及 totalMicro、acceptedLessons（本期发布）、activeClasses（本期有作答的班级）、两种分摊值（分母为 0 时为 null）、作业状态计数、人工支持分类与未归属条数。`GET/POST /api/edu/support-costs`：`{period, category: onboarding|review_support|incident|content|billing|other, minutes 1 至 100000, costMicro ≥ 0, subjectRef, note}`，记录人取当前用户并审计。
- 教育角色（DEV-013）：租户所有者、管理员或 org_admin。`POST /api/edu/roles` `{tenantId, userId, role: teacher|reviewer|org_admin, workspaceId?, expiresAt?, reason?}`：workspaceId 须属于该租户，org_admin 不可限定工作区；expiresAt 须晚于当前 1 分钟且不超过 3 年；已有绑定则续期并重新启用（审计 role.renew），否则新建（role.bind）。`POST /api/edu/roles/revoke` `{tenantId, userId, role, reason}`，理由必填，无有效绑定 404（审计 role.revoke）。`GET /api/edu/roles?tenantId=` 返回 `[{binding, effective: active|expired|revoked}]`。授权判定只认 active、未到期、租户范围或与当前工作区一致的绑定，到期与撤销在下一次请求生效。平台所有者与管理员不因管理绑定而获得教育角色。
- 来源权利（DEV-026）：本工作区教师或 org_admin 写，教职可读。`POST /api/edu/source-assets` `{title, kind: teacher_original|textbook|exam|publisher|web|other, attribution（非原创必填）, licenseRef, allowStudent, allowDerivative, allowExport, allowCrossOrg, expiresAt?}`；`GET /api/edu/source-assets`；`GET /api/edu/source-assets/:id` 返回 `{source, live, dependents: {problems, lessonRevisions, publications, activeAssignments, variantSets}}`；`PUT /api/edu/source-assets/:id/rights`（同字段加 reason 必填；已撤回 409）；`POST /api/edu/source-assets/:id/withdraw` `{reason}`；`PUT /api/edu/problems/:id/source` `{sourceAssetId}`（已挂接其他来源 409）。不允许的用途返回 409 RIGHTS_RESTRICTED（布置、迁移、变式生成）；学生读取不满足时按不存在处理。
- 课程配置（DEV-014）：本工作区教职。`POST /api/edu/courses` `{name, grade, textbook, textbookEdition, knowledgePoints[], allowedMethods[], notation: cn_textbook|latex_standard（默认 cn_textbook）, language: zh-CN|en（默认 zh-CN）, retainRevisions 1..500（默认 50）}`；`GET /api/edu/courses`；`GET /api/edu/courses/:id` 返回 `{course, alignments, classes}`；`PUT /api/edu/courses/:id`（同字段加 version，过期 409 VERSION_CONFLICT，返回 alignmentsNeedReconfirm）；`PUT /api/edu/classes/:id/course` `{courseId}`（空串解除）。对齐：`POST /api/edu/courses/:id/alignments` `{lessonRevisionId, knowledgePoints（须属本课程）, confirm, suggestedBy?}`，confirm 为 false 时为建议；`POST /api/edu/course-alignments/:id/confirm|reject`；`GET /api/edu/lesson-revisions/:id/alignments`。返回中 textbookAligned 仅在 state 为 confirmed 时为 true；课程教材、版次或知识点变化后已确认对齐退回 suggested，note 为 course_changed。
- 名单导入（DEV-016）：班级任课教师。`POST /api/edu/classes/:id/roster-import` `{csv（至多 64 KiB、500 行）, ttlHours?（默认且至多 336）, confirm}`，表头只接受 externalRef/学号/编号 与 displayName/显示名/昵称，其他列 400；externalRef 为 1..40 位字母数字下划线连字符，显示名至多 20 字，像手机号、身份证号或邮箱的值判为无效；confirm 为 false 时逐行返回 new、existing、invalid；有无效行时确认 409；确认 201 只新增新行，每行返回一次性认领码（只存 hash）。`GET /api/edu/classes/:id/roster-entries`（不含 hash 与码）；`POST /api/edu/classes/:id/roster-entries/:eid/reissue`（仅未认领，旧码即失效）；`POST …/revoke`（仅未认领；已认领者走退班）。班级名单 `GET /api/edu/classes/:id/roster` 增加 externalRef、displayName。
- 内容事故与撤回（DEV-027、AC-34）：本工作区教师或 org_admin。`POST /api/edu/publications/:id/incidents` `{severity: blocking|minor, reason 1 至 400 字, confirm}`（DEV-112：blocking 不带 confirm 只返回 `{dryRun: true, impact}`，不改任何状态），新建 201、已有未关闭事故 200（同一事故，minor 可升级为 blocking 并补跑撤回链）。blocking 在同一事务内：发布 withdrawn，讲解修订 withdrawn，active 任务改 suspended（作答保留），该修订的变式题组 withdrawn，学生受众产物 revoked_at（已签发链接立即 403/404）。返回 `{incident, impact: {assignments, classes, students, attempts, variantSets, revokedArtifacts, childRevisions}}`。`GET /api/edu/incidents?state=&publicationId=`、`GET /api/edu/incidents/:id`。`POST /api/edu/incidents/:id/resolve` `{fixPublicationId, note}`：blocking 必须给出已发布修正，其讲解修订沿编辑链是事故修订的后代，且绑定的审核记录为人工审核（inheritedFrom 为空）；否则 409。撤回版本的发布请求返回 409 POLICY_REVOKED。
- 任务迁移（DEV-025）：班级任课教师或管理员。`POST /api/edu/assignments/:id/migrate` `{publicationId, reason, confirm}`：confirm 为 false 时只返回预览（affectedStudents、attemptsKept、incidentId、variantSetDropped）；为 true 时 201，新建 active 任务（沿用时间与答案政策，不沿用变式题组），旧任务改 migrated，旧作答原样保留；同一任务只可迁移一次（409）。`GET /api/edu/assignments/:id/migrations`。迁移本身不改分数，重评分另行发起。
- 重评分（DEV-025）：班级任课教师或管理员。`POST /api/edu/assignments/:id/regrade` `{publicationId?, reason（1..200 必填）, confirm}`：参照发布默认取迁移目标，未迁移取任务自身发布；参照必须是已发布版本且为原讲解或其编辑后代（撤回版 409）。只重评有效主题作答（单次至多 300 条，超出 409 PARAMETER_LIMIT），用真实判分器按参照答案键判分；判分器失败或判为无效时跳过并列入 skipped，不改为错误。confirm 为 false 只返回预览 `{examined, changed: [{attemptId, studentUserId, oldResult, newResult, teacherJudged}], unchanged, skipped, affectedStudents}`；为 true 时 201，只写变化项：作答仍在原任务、原作答文本不变，result 更新、reason 记 regraded，另记 edu_regrades（旧结果、新结果、理由、参照发布、批次）；同一作答对同一参照只重评一次，重复确认 written 为 0。教师人工判定（teacherResult）保持不变并在预览中标出。`GET /api/edu/assignments/:id/regrades`。学生 `GET /api/edu/student/regrades` 返回本人通知（任务标题、旧结果、新结果、固定说明“老师修正内容后重新评分”，不含教师理由，防止理由中写出答案），`POST /api/edu/student/regrades/:id/seen` 标记已读，非本人 404。
- 重放（AC-46）：同一视图轮询任意次、乱序旧视图、终态后重复同步，都不会新增阶段记录或扣费。
