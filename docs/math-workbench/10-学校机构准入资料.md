# 10 学校机构准入资料（DEV-111 草稿）

本文件供学校或教育机构做准入评估时使用，内容按当前代码与文档如实整理。**状态：草稿，未经学校、法务或数据治理负责人核定。** 处理者与受托处理者等合同角色、监护人同意的适用方式、数据所在地域，须由数据治理负责人（DG）按实际业务核定；面向学校再服务学生（B2B2C）的模式不构成任何豁免。凡标注“未实现”或“待确认”的项目，不得在对外材料中写成已具备。

## 1 产品功能

| 功能 | 使用者 | 说明 | 依据 |
| --- | --- | --- | --- |
| 题目录入与分析 | 教师 | 结构化表单或文字题识别为草稿，教师确认后由数学服务求解与验证；目录外题目只能人工编写讲解，并标明未经自动数学验证 | 06、E50、E51 |
| 讲解生成、审核与发布 | 教师、审核员 | 审核绑定精确修订与哈希；有阻断错误不得发布；发布不可变，修改产生新修订 | 09 第 1 节 |
| 班级与任务 | 教师、机构管理员 | 建班、邀请码或名单导入认领、布置任务、个人延期、撤回任务（先预览影响） | 03、E59 |
| 学生学习 | 学生 | 作答、分层提示、自测、求助、复习；未开放的答案不进入学生接口、页面、缓存或媒体 | 09 第 2 节 |
| 学情与批改 | 任课教师 | 学情分布、求助分组回复、逐条判定、重评分（先预览后确认） | 03 |
| 机构治理 | 机构管理员 | 机构概览（只含汇总）、角色、审核与同意策略、个体访问须说明目的并审计、数据请求、保留策略、限时运维授权 | E52、E54、E55、E56 |
| 导出 | 教师、机构管理员 | 内容与学习报告导出 | E53 |

当前没有接入语音合成、视频生成或任何把学生数据发送给大模型的功能（见第 3 节）。

## 2 数据清单与数据流

### 2.1 收集的数据

| 类别 | 内容 | 来源 | 不收集 |

| 名单 | 学校内部编号（externalRef）、显示名、认领状态 | 教师或机构导入 | 导入时拒绝手机号、邮箱、身份证号格式（DEV-104） |
| 选课与角色 | 班级、选课状态、教育角色及有效期 | 系统记录 | |
| 同意 | 授予或撤回状态、证据编号（纸质或线下表单的编号，不存原件） | 机构管理员登记 | |
| 学习记录 | 作答、提示解锁、自测、预测、图形交互事件、复习、进度 | 学生使用 | 作答图片上传尚未实现 |
| 求助 | 求助类型与文字（不超过 500 字节，拦截个人联系方式） | 学生 | |
| 教师内容 | 题目、讲解、审核记录、来源权利 | 教师 | |
| 审计与访问记录 | 操作者、动作、对象、目的与计数 | 系统 | 审计不含作答或求助正文 |
| 用量与账本 | 数学作业计量、预算 | Go 平台 | |

### 2.2 数据流

1. 浏览器经平台 Go 后端访问 /api/edu；所有教育表在 PostgreSQL 中启用 FORCE RLS，按租户隔离，服务端再做班级、任课、选课与任务受众检查。
2. 数学求解与渲染由数学服务处理，平台发送题目参数与讲解内容，不发送学生身份。数学服务在隔离子进程中运行，不继承平台密钥，不执行用户或模型提供的代码。
3. 学生作答按发布时固定的答案判分：平台把作答表达式与该答案发给同一部署内的数学服务比对，请求只带租户编号，不带学生编号、姓名或其他作答记录；判分不调用外部服务。
4. 产物（讲解预览等）经短时签名链接取件，取件时复核权限，撤回后立即失效。
5. 日志只记录请求方法、路径（不含查询串）、状态、耗时、来源地址与请求编号，不含请求体（E58）。

### 2.3 处理目的与服务方

| 处理 | 目的 | 服务方 | 状态 |
| --- | --- | --- | --- |

| 教育数据存储 | 提供教学与学习功能 | 平台自身数据库（部署方选择的服务器） | 已实现；具体机房与地域由部署方确定 |
| 数学求解、渲染与判分 | 生成与验证讲解，比对作答 | 数学服务（平台自有组件，同一部署内） | 已实现 |

| 供应商地域与出站约束 | 保证数据只发往批准地区 | 无 | 未实现，阻塞（DEV-105）；机构概览如实显示“未配置” |

平台不把机构内容、学习记录用于跨租户训练、公共题库或默认共享。

## 3 权限

- 学生不获得工作区成员身份或查看权限，只能访问本人在册班级中、对其开放的任务（09 第 1.1 节）。
- 教师只看自己任课的班级；机构管理员查看不任课班级的个体学生记录时必须填写业务目的，每次访问写审计并列入访问记录（E52）。
- 运维人员默认看不到学校数据；须机构管理员按目的、范围与期限（最长 72 小时）授权，可随时撤销，每次查看写审计（E56）。运维直连数据库只能依靠部署控制（07 v91）。
- 全路由越权扫描（E44）覆盖全部教育接口，新增接口自动纳入。

## 4 治理

| 事项 | 机制 | 状态 |
| --- | --- | --- |
| 审核策略 | 自审、需审核员、双人审核，由机构设置 | 已实现 |
| 同意策略 | 机构可要求监护人同意；未同意的学生不能作答；设为不适用须填写理由并审计 | 已实现；适用方式由 DG 核定 |
| 内容事故 | 阻断事故先预览影响，确认后撤回发布、暂停任务、撤销学生产物；须以人工审核的修正版本关闭 | 已实现（E59） |
| 数据保留 | 建议值：临时 7 天、图片 90 天、学习记录 180 天、备份 30 天；机构确认前不执行清理 | 进行中（DEV-106） |
| 备份恢复 | 恢复后重放删除标记，已删除的数据不会因恢复而重新出现 | 已实现（E55） |
| 许可与来源 | 依赖与素材清单见 06；教师上传题目须登记来源权利 | 清单已生成，待正式复核（DEV-110） |

## 5 权利流程

学生或监护人通过学校提出请求，由机构管理员在“数据请求”中登记，记录线下身份核验后处理（E55）：

| 请求 | 处理结果 |
| --- | --- |
| 查阅 | 生成一次性副本（选课、同意状态、认领名单、作答、求助、各表计数），平台不保存副本 |
| 撤回同意并停止处理 | 撤销学生身份与同意、移出班级，记录保留 |
| 删除学习记录 | 在上一项基础上在线删除本机构全部班级中的学习记录与名单认领；备份按保留期到期；账本用量与审计按法定或合同要求保留 |

处理前均预览影响；完成后写审计（只含计数）。删除范围仅限教育数据，平台账号注销沿用平台流程（05 待确认问题 19）。

## 6 待学校与负责人确认（准入前）

1. 合同角色：学校与平台运营方在学生数据处理中的角色与责任，由 DG 按实际业务核定，并写入服务协议。
2. 监护人同意：适用年龄、同意形式与证据留存方式。
3. 数据地域与出站约束（DEV-105 阻塞）：未实现前不得对外声明“数据仅在某地区处理”。
4. 保留期：机构确认具体天数后才执行清理（DEV-106）。
5. 平台账号注销与教育数据删除的衔接（05 待确认问题 19）。
6. 真实学生使用前，完成授权、必要同意、隐私与数据隔离的前置要求；本仓库的自动测试与本草稿不构成人工验收或真实集成验证。
