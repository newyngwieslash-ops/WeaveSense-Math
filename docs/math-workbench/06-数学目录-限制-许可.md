| CONIC-CHORD-01 | 椭圆 x²/a²+y²/b²=1（a>b>0）过右焦点的弦长范围 [2b²/a, 2a]；最大值在水平弦（长轴），最小值在竖直弦（通径），两端均可取到；用焦点极坐标式独立核验，单调性与判别式符号检查 | dev |

| CONIC-PARABOLA-01 | y²=2px（焦点 (p/2,0) 的教材约定），过焦点弦 OA·OB = −3p²/4；排除 x 轴；对所有直线 x = my + p/2 做符号恒等式 | dev |

这六个题族是有限参数题族，**不是通用解题能力**。目录外的题目返回 UNSUPPORTED_FAMILY，不做尝试。

## 使用限制
- 参数为精确有理数或简单根式文本，有长度与大小上限（见 catalog.LIMITS）；不接受任意表达式。
- 各阶段的预算按子进程 CPU 时间计（RLIMIT_CPU，秒数取各阶段上限），主机繁忙时不会把便宜的阶段误判为超时；另设预算 6 倍的墙钟上限，结束阻塞或长期得不到 CPU 的阶段。两种情况都记为 TIMEOUT_UNDETERMINED（无法判定），不是无解。计量的 compute_ms 仍为墙钟耗时。
- 证据分层：exact_symbolic（符号精确）、independent_closed_form（独立闭式比对）、synthetic_route（综合法路线）、numeric_sampling（数值抽样，不是证明）、manual_review（人工复核，单独标注）。
- 有限变式（variant_set）：从各族 VARIANTS 表取候选，只改数字（change_type numbers_only，近迁移），每题重新求解与验证，与原题或其他变式答案相同的剔除，单次最多 5 题，不足不补凑。SOLID-ANGLE-02 只有 2 个不同答案的变式；SOLID-ANGLE-01 答案为常数，没有可用变式。
- 题族准入需要数学教研人工确认，目前没有任何题族完成人工准入。
- 工程回归集（services/math-service/tests/test_regression.py）：六族共 174 个正例、31 个拒绝样例，期望答案来自手推闭式、不调用求解器，全部通过。它**不是** FR-Q01 要求的 240 个教师独立编写与复核的冻结验收集，只用于防止实现回退。
- 学生答案守卫：若某个答案标记本身出现在题面、已知参数或自测题题干中（例如整数答案 3 恰好出现在 x²/3 里），该标记无法区分泄露，守卫跳过它；结构性检查（无 answer、无答案键、讲解全部锁定）仍然生效。静音网页只对可见文字做检查，SVG 坐标与样式不参与。

说明：
- 上面 Go 模块与前端库“没有 GPL、LGPL、AGPL 或 MPL 类依赖”的结论只针对链接进平台程序的库；操作系统层含 GPL 程序（BusyBox、apk-tools、GNU Wget）与 MPL 数据（ca-certificates），它们是镜像中独立的程序或数据，义务是附许可并提供源码获取方式，不影响平台代码的许可。
- 镜像按标签引用（如 node:22.19-alpine），标签会随上游补丁移动。发布时应记录实际拉取的 digest（07“容器镜像名”一节已要求 .env 用带 digest 的镜像），是否在 Dockerfile 中改为 digest 固定由部署负责人决定。
- 数学服务目前没有镜像，以 python -m mathsvc.server 运行（07）。运行时只需 CPython（PSF-2.0）与 requirements.txt 中固定的 sympy、mpmath（均 BSD-3-Clause），不需要系统字体或其他系统包；部署方若为其制作镜像，须把所用基础镜像与系统包补登到本表。
- services/loom-engine 下的镜像属于平台的其他服务，不在本模块的分发清单内。
