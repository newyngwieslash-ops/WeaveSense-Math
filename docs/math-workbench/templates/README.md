# 外部事项记录模板

配合 [12-外部事项操作指南.md](../12-外部事项操作指南.md) 使用。复制模板到 `docs/math-workbench/records/`（或机构自己的受控存储）后填写，文件名用 `U<编号>-<YYYYMMDD>-<序号>.md`，例如 `U15-20261102-01.md`。

| 模板 | 用于 |
| --- | --- |
| [U3-负责人与工时表.md](U3-负责人与工时表.md) | U3 各事项负责人与可用工时 |
| [U1-数学审阅签字单.md](U1-数学审阅签字单.md) | U1 数学负责人逐族审阅、冻结参数范围与 FR-Q01 准入集 |
| [U2-冻结案例集格式.md](U2-冻结案例集格式.md) | U2 240 例冻结集的 CSV 与 JSON 字段约定 |
| [U4-监护人同意核对单.md](U4-监护人同意核对单.md) | U4 同意方式、证据编号规则与 DG/学校审阅 |
| [U13-保留期决定记录.md](U13-保留期决定记录.md) | U13 机构核定保留天数 |
| [U14-许可复核清单.md](U14-许可复核清单.md) | U14 许可正式复核与基础镜像 digest 决定 |
| [U12-恢复演练记录.md](U12-恢复演练记录.md) | U12 备份恢复演练、重放与 RPO/RTO 实测 |
| [U15-无障碍与真机验收记录.md](U15-无障碍与真机验收记录.md) | U15 键盘、读屏、真机、弱网验收；U16 设备清单 |
| [U18-试点协议核对单.md](U18-试点协议核对单.md) | U18 试点协议、定价口径与 AC-61 证据 |

通用规则：
* 不写任何密钥、口令、令牌、连接串中的密码、内网主机名。需要引用时写“见密钥管理条目 <名称>”。
* 不写真实学生姓名、手机号、身份证号、邮箱、学号原值；学生一律用假名编号（与名单导入的 externalRef 规则一致：字母、数字、下划线、连字符，1 至 40 位）。
* 签字件、同意书原件等含个人信息的材料留在机构受控存储，记录里只写证据编号与存放位置描述。
* 时间写明时区，例如 `2026-11-02 10:30（UTC+9）`。
* 记录是证据，不是结论：未执行的项写“未执行”，不填“通过”。
