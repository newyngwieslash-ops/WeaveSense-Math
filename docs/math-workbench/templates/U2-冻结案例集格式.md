# U2 冻结案例集格式（CSV 与 JSON）

开发侧尚无冻结集导入命令（DEV-113 至 115 阻塞），本格式是交给开发侧接入的约定。字段名用英文以便机器读取，内容可用中文。冻结集本身由独立教师编写，开发侧不得编写、不得查看盲测部分的答案。

## 文件
* `frozen_set_<版本>.csv`（或 `.jsonl`，每行一个 JSON 对象，字段相同）
* `frozen_set_<版本>.sha256`：上一个文件的 sha256
* 盲测部分（split=blind）的 expected_* 字段单独存一份 `frozen_set_<版本>_blind_answers.csv`，只交给评测执行人，不进入仓库、Skill、检索或调试日志。

## 字段
| 字段 | 必填 | 说明 |
| --- | --- | --- |
| case_id | 是 | 唯一编号，例如 FQ-0001 |
| category | 是 | supported（支持，150 例，每族不少于 25）/ image（图片、转写、冲突，30）/ illegal（非法或不支持，30）/ teaching（教学、交互、呈现，30） |
| family_id | 支持类必填 | SOLID-VOL-01、SOLID-ANGLE-01、SOLID-ANGLE-02、CONIC-CHORD-01、CONIC-SLOPE-01、CONIC-PARABOLA-01；不支持类写 none |
| split | 是 | dev（开发回归，可公开给开发侧）/ blind（盲测） |
| source_group | 是 | 来源或模板分组编号，同组案例必须在同一 split，防止泄漏 |
| derivation_branch | 否 | 推导分支标签，例如 geometric、coordinate |
| problem_text | 是 | 题面原文（不得含学生个人信息） |
| image_ref | image 类必填 | 图片文件相对路径与 sha256；图片版权见 source_license |
| structured_input | 支持类必填 | 与平台 POST /api/edu/problems 的 structured 字段一致的 JSON，例如 `{"family_id":"SOLID-ANGLE-02","input_state":"sufficient","unit":"","params":{"a":"2","h":"1"}}` |
| expected_outcome | 是 | answer（应给出答案）/ refuse（应拒绝）/ needs_confirmation（应要求确认题意）/ needs_teacher（应转人工） |
| expected_answer | answer 时必填 | 精确形式，例如 `2*sqrt(22)/11`；区间写 `[lo, hi]` |
| expected_unit | 否 | 单位 |
| expected_error_code | refuse 时必填 | 例如 UNSUPPORTED_FAMILY、PARAMETER_LIMIT（取值见 03 错误码） |
| severity_if_wrong | 是 | blocker（数学阻断）/ major / minor；数学阻断不得被其他维度的分数抵消 |
| reviewer_1 | 是 | 第一位合格审阅者（姓名或工号，按机构规定） |
| reviewer_2 | blocker 争议时必填 | 第二位审阅者 |
| dispute_note | 否 | 争议与裁决说明 |
| source_license | 是 | 原创 / 教材引用（注明版本与授权）/ 其他（注明） |
| author | 是 | 编写人（独立教师） |
| frozen_at | 是 | 冻结时间与时区 |

## CSV 示例（一行，示意格式，不是真实案例）
```csv
case_id,category,family_id,split,source_group,derivation_branch,problem_text,image_ref,structured_input,expected_outcome,expected_answer,expected_unit,expected_error_code,severity_if_wrong,reviewer_1,reviewer_2,dispute_note,source_license,author,frozen_at
FQ-0001,supported,SOLID-ANGLE-02,dev,G-01,geometric,"正四棱锥 P-ABCD 底边 2，高 1，E 为 PC 中点，求 BE 与平面 PAC 所成角的正弦",,"{""family_id"":""SOLID-ANGLE-02"",""input_state"":""sufficient"",""unit"":"""",""params"":{""a"":""2"",""h"":""1""}}",answer,2*sqrt(22)/11,,,blocker,教师甲,,,原创,教师乙,2026-11-10 18:00（UTC+9）
```

## 交付自检
* 总数 240；supported 150 且每族不少于 25；image、illegal、teaching 各 30。
* 每个 source_group 只出现在一个 split。
* 文件不含学生个人信息。
* 已计算 sha256 并与文件一并交付。
