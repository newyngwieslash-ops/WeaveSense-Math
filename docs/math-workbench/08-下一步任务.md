### A1 DEV-083 教师端屏幕阅读器与键盘验收（用户 2026-10-27 决定：用户拉取项目后在本地完成）
DEV-083 在用户报告结果前保持“进行中”。自动化部分（错误码中文说明、可访问名称、role=status 与 role=alert、空态与下一步）已有测试，本项只做人工部分，不以自动测试冒充。

**本地启动**（命令取自仓库 README“本地开发”与 07 配置项；三个终端）：
1. 数学服务：`cd services/math-service && python -m pip install -r requirements.txt && MATH_SERVICE_KEY=<至少 32 字节的本地随机串> python -m mathsvc.server`（默认监听 127.0.0.1:8790，数据在 ./data）。
2. 后端：按 README 的“终端一”命令启动 `go run ./cmd/server`，并额外设置 `FLOW_MATH_SERVICE_URL=http://127.0.0.1:8790` 与 `FLOW_MATH_SERVICE_KEY=<与上面相同>`；未设置时 /api/edu 不注册。
3. 前端：`cd web && bun install --frozen-lockfile && bun run dev`，打开 http://localhost:3000，注册管理员账号。
4. 角色：用该账号在自己的个人租户（`GET /api/edu/me` 可见用户 id，租户为 `tn_u_<用户id>`）调用 `POST /api/edu/roles`，体 `{"tenantId":"tn_u_<用户id>","userId":"<用户id>","role":"teacher"}`（见 03）。学生视角用第二个账号：教师在 /edu/teach 建班生成邀请码，学生账号加入，教师登记同意后布置任务。
5. 可先在教师首页生成示例题与示例班级，便于看到有内容与空态两种情况。
说明：以上组合启动步骤由 README 与 07 拼合，开发侧只在测试与 CI 中验证过各部分（`bun run test:edu:e2e` 走同样的数学服务与前端代理），未在全新机器上整体演练；遇到启动问题请一并记入结果。
